# FBL Skyhold Manager

Менеджер владений для Forbidden Lands в Foundry VTT: жители, здания, труд, склад, хозяйство, торговля, корабли, Политика и массовый бой.

Основная игровая среда — Foundry **13.351** / Forbidden Lands **13.0.5**. Сохраняется поддержка Foundry 14; manifest указывает проверенные версии 14.364 / 14.0.4. Статические проверки совместимости не заменяют проверку конкретного мира.

## Установка и открытие

1. Разместите модуль в `Data/modules/fbl-skyhold`, с `module.json` непосредственно в этой папке.
2. Включите его в настройках мира и перезагрузите страницу клиентов.
3. Откройте менеджер кнопкой модуля или макросом `game.fblSkyhold.open()`.

ГМ создаёт и настраивает владения. Публичное владение доступно игрокам согласно настройкам; скрытое не должно появляться в обычных окнах, отметках сцены и общем чате.

## Работа с владением

| Раздел | Что в нём делать |
|---|---|
| Обзор | Описание, население, довольство, репутация и развитие по четырём направлениям |
| Жители | Карточки, жильё, назначения, жалованье, состояние и связь с Actors |
| Здания | Шаблоны, стройбригады, проекты, производство, службы и обслуживание |
| План работ | Постоянный штат и задания QD, основная/резервная работа, цели и предложение распределения |
| Склад | Ресурсы, FIFO-партии, предметы, помещения, казна и история |
| Внешний рынок | Товары, перевозки, банки и флот; подтверждение покупки/продажи открывает расчёт перевозки |
| Политика | Контроль, представитель, директивы, указы, обращения и история; доступ зависит от развития и прав |
| Оборона и Особое | Отряды, массовый бой, специальные записи и функции владения |
| ГМ | Каталоги, настройки прав, события и явные служебные операции |

Полные действующие правила и отдельные проекты находятся в [указателе документации](docs/README.md). Наличие проекта в репозитории не означает наличие функции в игре.

## Хозяйственный цикл

1. Назначьте людей, жильё, работу, рецепты и обслуживание. **QD** — четверть дня; взрослому по умолчанию доступны 20 обычных рабочих QD за десятник.
2. Проверьте питание, казну, сырьё и места хранения. Зарплата начисляется по оплачиваемому назначению; отсутствие выпуска само её не отменяет.
3. ГМ открывает расчёт целого десятника или пакета десятников. Если перевозке требуется решение, сначала появляется разбор происшествий.
4. Предпросмотр показывает изменения без проведения хозяйства. Решение транспортного происшествия — отдельная сохраняемая операция, явно подтверждаемая ГМом.
5. ГМ проверяет результат и проводит его. Пакет считается последовательно и записывается атомарно; изменение исходных данных требует нового расчёта.

Складские поступления и выручка учитываются по правилам перевозок и хозяйственных фаз. Возврат бюджета корабля, заём и снятие основной суммы вклада не являются прибылью. Остаток товара также не равен деньгам.

## Права игроков

ГМ отдельно разрешает управление жителями, зданиями, строительством, складом, казной, кораблями и политическими действиями. Открытие окна не предоставляет все права записи. Изменения игрока выполняет активный authority-GM; без него операция показывает причину недоступности.

На складе игрок с соответствующим правом может перемещать позиции между помещениями. Изменение количества, признака продажи, заметок строки, казны, удаление и передача предметов персонажам доступны ГМу. Общие заметки склада не имеют доступного игроку поля редактирования.

ГМ проводит хозяйство, разрешает скрытые события и меняет каталоги. Настройки и интерфейс должны скрывать GM-only сведения при обычном использовании. Модуль рассчитан на доверенную дружескую группу; границы разработки определены в [AGENTS.md](AGENTS.md).

## Обновление и сохранения

Обновление кода не означает обновление сохранённого каталога или применение перехода труда. Обычная загрузка сохраняет пользовательские настройки. Preview не разрешает Apply: замену дерева, переход труда и импорт выполняет ГМ отдельным явным действием после проверки последствий. См. [руководство по переходам и восстановлению](docs/migrations.md).

Прежние рыночные заказы читаются как совместимая история; незавершённые поставки старого формата автоматически не переводятся в перевозки v2. Старые принятые клиентские договоры корабля сохраняют свои условия.
