# Достижимость после утверждённых изменений развития

Дата проверки: 2026-09-14. Сравнение исторического каталога v15 с действующим v16; изменения досуга описаны в [правилах v16](morale-v16-implementation.md). Отчёт воспроизводится командой `node scripts/dev/build-building-development-route-report.mjs`; `--check` сверяет файл без записи.

**Открываются все 124 здания дерева.** Два сюжетных шаблона в дерево не входят. Итог развития: **102/164/149/113** вместо 104/164/149/113. Добавлены пять заведений досуга, снижено развитие Трактира, Театра и Музея. Прежние требования и зависимости сохранены.

Проверяются числовые требования, зависимости И/ИЛИ и обязательный Центр Строительства. Все поставщики считаются исправными и работающими. Развитие каждого шаблона начисляется один раз. Это структурная проверка: она не моделирует деньги, длительность строительства, кадры, географию, снабжение или ролевые разрешения.

Отдельный поиск опорного маршрута выполнен для каждого здания. Максимум до правки — 55, после — 58 построек. Каждый найденный шаг перепроверен теми же воротами, что массовые волны. Маршрут эвристический: его длина не является минимумом и сама по себе не доказывает оптимальную экономику.
