# Документация Skyhold

Состояние сверено с веткой PR #14 на 10 ноября 2026 года. [Руководство пользователя](../README.md) описывает вход в модуль. Реализация, применение к конкретному миру и живая проверка Foundry — разные статусы. Ни документ, ни успешный тест не разрешают Apply.
