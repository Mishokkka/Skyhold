## Источники генерации и совместимость

Историческая версия и слово `proposal` в имени не означают, что файл можно удалить. Таблицы ниже читают генераторы и characterization-проверки.

|---|---|

| [Редакция v15](building-preparation-revision-2026-09-05.md) | `build-building-catalog-v15.mjs`, подготовка и сравнение переходов |
| [Принятые бонусы](building-development-approved.md) | `building-development-approved-data.mjs` |
| [Профили работников](building-worker-affinity-proposal.md) | `build-building-worker-profiles.mjs` |
| [Нормы обслуживания](building-maintenance-proposal.md) | `building-maintenance-proposal-check.mjs` |
| [Дополнения команды JSON](magnifique-crew-additions.json) | `build-magnifique-crew.mjs`, проверка состава |

[Каталог зданий](building-catalog.md) и [достижимость](building-development-reachability.md) генерируются из кода; их сверяют соответствующие `build-*.mjs --check`.

[Ранний корабельный контракт](settlement-ships-storage-contract.md) и [ручные предложения](ships-contracts-stage.md) сохранены для прежних рейсов и ещё не завершённых частей замысла. Они не определяют поведение новых мировых заказов.

Удалены заменённые аудиты довольства, исходный аудит бонусов, повторные корабельные отчёты и разбор старого флота. Принятые правила и ручные проверки сведены в основные документы; девять биографий дополнений перенесены в инструкцию команды.
