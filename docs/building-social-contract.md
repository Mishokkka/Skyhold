# Довольство, Репутация и работа служб

Действующие правила социальных эффектов для каталога v19 ([каталог](building-catalog.md), [труд](labor-contract.md)).

## Подтверждённая деятельность

- План назначения — прогноз. Положительный эффект работающей службы проверяется по следу последнего завершённого десятника, присутствующим доступным работникам с подходящими назначениями, выполненному труду, оплате, исправности и зависимостям.
- В `legacy`-режиме действуют пороги состава и QD; в гибридной модели коэффициент определяется фактически зачтёнными QD относительно нормы функции (обязательная квалификация сохраняется). Пассивные объекты (например, Колодец) не требуют работника, но проверяют состояние, содержание и зависимости.
- После простоя основная служба засчитывает труд только после завершённой оплаченной технической проверки.

## Повторы, охват и досуг

- Развитие одного `templateId` начисляется один раз. Положительные глобальные эффекты повторов ограничены, если не задано `repeatSettlementEffects`.
- Физические мощности (выпуск, жильё, склад, оборона, Контроль, охват услуг) сохраняются у каждого экземпляра.
- Услуга с охватом масштабируется по активной вместимости относительно населения; адресная требует выбранных получателей. Повтор расширяет охват, а не умножает фиксированный бонус.
- Явно настроенный `service.leisure` ограничен трудом и нормой QD/ед.; повтор одного вида досуга ослабляется по рангу работающих зданий: **100% → 75% → 50% → 25%** (округление вниз; неработающее здание ранг не занимает).
- Отрицательные эффекты не исчезают из-за неоплаты. Досуг, Репутация, довольство и условия труда считаются своими источниками (единого «гармонического» коэффициента нет).

## Интерфейс и владельцы

- Карточка владения показывает фактически зачтённый эффект; шаблон — номинал. Изменение шаблона не переписывает сохранённые экземпляры без явного [перехода](migrations.md).
- Владельцы: `scripts/engines/economy/building-service.js`, `scripts/apps/domains/{resident-domain,building/development-domain}.js`, `scripts/data/building-labor-catalog.js`. Проверки: `suite:economy`, `workers:check`, `tenday:check`, [общая матрица](manual-foundry-smoke-matrix.md).
