# API уникальных зданий

Действующий extension contract для встроенных и сторонних приложений отдельных зданий.

## Регистрация и поведение

Если у здания задан дискриминатор `building.special.kind`, зарегистрированный в `game.fblSkyhold.uniqueBuildings`, клик по зданию открывает его ApplicationV2 вместо стандартного редактора. Неизвестный или недоступный `kind` всегда откатывается к стандартному редактору.

```js
game.fblSkyhold.uniqueBuildings.register("example-kind", {
  appClass: ExampleBuildingApp,
  label: "Example building",
  source: "my-module"
});
```

## Контракт

- Запись остаётся обычным зданием: отображается в менеджере, перетаскивается на сцену, участвует в строительстве и сохраняет общие поля (`name`, `image`, `status`, `notes`, `workers`, `storage`).
- Уникальные данные хранятся в `building.special.data`, если не принадлежат общей подсистеме (например, `building.medical`).
- Приложение использует стандартные транзакции `SkyholdData` и права владения, а также сохраняет доступ к общим вкладкам управления зданием (как минимум `Основное` и `Строительство`).
- Спойлер-контент оформляется через шаблон каталога с `visibility: "gm"`: скрытые шаблоны видны только ГМу в скрытом разделе браузера и создают скрытые экземпляры.

## Встроенные виды

- `medical` — окно лазарета с интеграцией медицины и массового боя.
- `fasti-shop` — скрытый сюжетный шаблон кампании Лапуты с атомарными взносами из казны, историей операций и порогом открытия `3999.9 GP`.
