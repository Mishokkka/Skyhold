# Единые высоты элементов — 4 октября 2026

Реализовано по согласованному аудиту высот. Включены внутренние вкладки редактора здания; компоновка карточек зданий остаётся отложенной.

## Результат

- Однострочные поля, списки, поиск, обычные кнопки и иконки используют `--fbls-control-height: 2rem`: 32 px при корневом шрифте 16 px, 40 px при 20 px.
- Для плотных строк введён минимум `--fbls-row-height: 2.5rem`: 40 / 50 px. Строка может расти из-за многострочного содержимого. Нативные отступы таблиц жителей и матрицы контртипов больше не добавляют лишнюю высоту.
- В редакторе здания подпись занимает одну строку, где подходит сокращение; зазор до поля — 2 px. Значения в режиме просмотра имеют ту же высоту, что и поля ввода. Полное название сохраняется в `title`, доступном имени поля и существующей подробной подсказке.
- Примеры: «Максимум довольства» → «Макс. ДОВ», «Мин. работников досуга» → «Мин. работн.», «Эксплуатация / мес.» → «Экспл. / мес.». Длинный текст не скрывается без возможности прочитать полное название.
- Сетки редактора перестраиваются по ширине его окна. Исправлена денежная вкладка: новый набор полей больше не получает узкие колонки старой сетки менеджера, предназначенные для чекбоксов.
- Textarea, списки `multiple` / `size`, range, checkbox и скрытые input сохраняют собственную геометрию. В составном поиске выравнивается внешняя оболочка; внутренний input занимает её доступную область.
- Многострочные поля редактора используют общую типографику и читаемый цвет placeholder; нативная тема больше не делает подсказку тёмной на тёмном фоне.

## Владение

Размеры принадлежат `styles/parts/skyhold-variables.css`; общие поля и строки — `skyhold-forms.css` / `skyhold-ui-kit.css`. Нативные правила Foundry для этих ролей собраны в `skyhold-form-bridge.css`, отдельно от оконной рамки и меню select.

Поля и сетки редактора здания находятся в `current/skyhold-current-building-editor-fields.css`, оболочка — в `skyhold-current-building-editor.css`, работники и производство — в своих существующих владельцах. Сетка культуры перенесена из лениво загружаемых стилей каталога в владельца полей редактора. Сетки денежных вкладок менеджера ограничены главным окном. Доменным файлам остаются ширина, расположение, переносы и составные элементы.
