# Каталог зданий v19

Автогенерируемый справочник встроенного каталога (126 шаблонов: 124 дерева и 2 сюжетных). Источник — `scripts/data/building-templates.js`. Обновление: `node scripts/dev/build-building-catalog-reference.mjs` (сверка: `--check`). Маршрут открытия конкретного здания: `node scripts/dev/building-development-reachability-check.mjs --route <id>`. Сохранённые миры не меняются автоматически — см. [переходы](migrations.md).

Обозначения: П/Т/К/В — Пища/Технология/Культура/Война; деньги — ММ (содержание за месяц, ставка за день); техобслуживание v2 — прямые QD/десятник (указано, если > 0); нулевые и пустые блоки опущены. Правила: [экономика](economy-contract.md), [труд](labor-contract.md), [службы](building-social-contract.md).
