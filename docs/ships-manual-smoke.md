# Корабли: ручной чеклист

Проверка в тестовой копии мира на Foundry 13.351 / 14 (ГМ, игрок с правом кораблей, игрок с правом жителей, игрок без прав). Итог записывается в [общую матрицу](manual-foundry-smoke-matrix.md); правила — в [ships-world-stage.md](ships-world-stage.md). Перевозка груза поселения проверяется отдельно в [transport-v2-validation.md](transport-v2-validation.md).

## 1. Окно, валюта и бюджет

- [ ] Открыть флот и окно судна (все вкладки, старое судно, пустой список, полный экипаж 36): размер, вкладка, ввод, раскрытия, фокус и прокрутка сохраняются при rerender; отказ ленивой загрузки допускает повтор.
- [ ] Единый формат валюты `З / С / М` (`1 З = 10 С = 100 М`) во всех экранах корабля, сводке флота, диалогах и уведомлениях; числовые поля ввода принимают золотые с точностью `0,01` (`1 М`).
- [ ] Предпросмотр заказа дома: показаны прямая стоимость рейса, единый бортовой запас, итого на борту, списание из казны и детальная разбивка в раскрытии; работают 1-клик пресеты **«С запасом»** и **«Только рейс»** с сохранением фокуса.
- [ ] Сводка финансов разделяет зарезервированные будущие участки связки и contingency-запас; предупреждения о нехватке различают ближайший участок, дальнейшие расходы и резерв с точной суммой дефицита.

## 2. Доска, клиентские договоры и время

- [ ] Доска (0–4 дела, включая пустую) сохраняется для порта/периода; повторное открытие не перебрасывает; игрок с правом запрашивает первую доску через authority-GM; реролл свободных дел доступен только ГМу.
- [ ] Выбор 1–3 совместимых дел, подхода капитана (обычный/осторожный/рискованный) и бюджета: порядок погрузки/доставки, трюм каждого участка (включая явный трюм `0`), погрузка в чужом порту, разбор пустого подхода до вылета, сезон следующего участка, без дубля сборов на карточку.
- [ ] Скоропортящийся клиентский груз: отбор заведомой порчи, возраст с погрузки, порча после задержки обнуляет плату за эту партию при сохранении расходов; старый договор без срока остаётся прежним.
- [ ] После десятника последовательно завершить короткие рейсы на днях 3, 5, 8; следующий длинный проходит только 2 дня к дню 10 без скрытой стоянки.
- [ ] Нехватка бортовых денег: перезагрузка, пополнение, повтор — тот же исход, один платёж, неоплаченный счёт виден отдельно и не дублируется в будущий резерв; ошибка чата не скрывает commit.
- [ ] Дома перевести бюджет на борт; за границей расходы идут из кошелька; возврат объединяет остаток один раз; `currentOuting` / `lastOuting` (> 40 строк, неполный старый учёт) не теряют суммы, домашнее содержание после возврата не меняет итог.

## 3. Экипаж, содержание, карта и права

- [ ] Переключение `homeUpkeepEnabled` ГМом посреди периода: новый домашний расход 0, старый долг остаётся, рейс/чужой порт/берег оплачиваются; игрок настройку не меняет.
- [ ] Отдых на борту → «В поселение» → жильё/работа → «Вернуть на корабль» → отправление/возврат: раздельные права жителей и кораблей, очистка назначений без автовосстановления, нет двойной еды/зарплаты и отсутствующих в бою/медицине.
- [ ] Готовность команды (мёртвый, раненый, несовершеннолетний, дубль, чужое судно): недобор блокирует новый договор, сохраняет принятый и разрешает допустимый возврат.
- [ ] Карта планировщика (pan/zoom, клавиатура, узкое окно, обе темы Foundry); скрытый рынок маскируется в финансах игрока; повтор/потеря ответа, отзыв права, смена authority и stale-ревизия.
- [ ] Удаление допустимого домашнего судна ГМом не трогает жителей/Actors; активный рейс, бортовые деньги, долг и транспортные обязательства блокируют удаление и перенос дома.
- [ ] При разрешённом тесте «Магнифика» (27+9): сопоставление, отказ при неоднозначности/чужой приписке, повтор без дублей, сохранение правок, World Actors не создаются; у игрока кнопки нет.
