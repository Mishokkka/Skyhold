# Каталог ресурсов v5

Автогенерируемый справочник встроенных данных (100 записей: 99 товаров и деньги; поголовье ведётся отдельно по 8 видам). Источник — `scripts/data/resources/resource-base-definitions.js` и `resource-unit-notes.js`. Обновление: `node scripts/dev/build-resource-catalog-reference.mjs` (сверка: `--check`).

`categoryTag` разрешает замену сырья в рецептах; `marketTags` служат только для рынка. 1 ед. нагрузки = 4 points; срок указан в QD (4 QD = день, `0` — не портится). Масса и объём в описании единицы носят пояснительный характер; склад и перевозки считают целые ЕД. и грузовые очки. См. [калибровку](resource-pricing.md) и [экономику](economy-contract.md).
