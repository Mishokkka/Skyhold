# Каталог ресурсов v5

Статус: сгенерированный справочник встроенных данных. 100 записей: 99 товаров и служебные деньги. Поголовье ведётся отдельно по восьми видам. Источник — `scripts/data/resources/resource-base-definitions.js`; смысл единицы — `resource-unit-notes.js` в той же папке.

Обновление: `node scripts/dev/build-resource-catalog-reference.mjs`; сверка без записи: та же команда с `--check`. Сохранённый пользовательский каталог может отличаться. [Калибровка цен и единиц](resource-pricing.md), [экономика](economy-contract.md).
